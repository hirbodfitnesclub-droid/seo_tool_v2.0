# PROJECT.md — SemanticLink (پیشنهاد لینک داخلی مبتنی بر امبدینگ)

> **نسخهٔ ۳.۰ — موتور رتبه‌بندیِ قطعیِ هیبریدی.** فاز ۲ (امبدینگ برداری خالص روی Supabase) کامل شد اما کیفیت رتبه‌بندی برای ۵۷۶ صفحهٔ بسیار مشابه («تور X») ضعیف بود. در نسخهٔ ۳ رتبه‌بندی از «کسینوسِ تک‌برداریِ خالص» به **امتیازِ هیبریدی = بردار معنایی + هم‌پوشانیِ وزن‌دارِ تگ‌ها** ارتقا می‌یابد؛ کل محاسبه در Postgres، قطعی، بدون هزینهٔ هوش مصنوعی، و همراه با **دلیلِ خودکارِ رتبه** برای هر صفحه.

---

## هدف بیزینس
ابزار داخلیِ سبک برای تیم سئو: مجموعهٔ صفحات سایت (≈۵۷۶ صفحهٔ تگ‌خورده) یک بار امبد و در Supabase ذخیره می‌شوند؛ سپس سیستم **به‌صورت خودکار و قطعی** برای هر صفحه ۳۰ صفحهٔ مکملِ لینک داخلی را رتبه‌بندی می‌کند و برای هر پیشنهاد **توضیح می‌دهد چرا این رتبه را گرفت**. هدف: ابزار مثل یک «متخصص سئو» رفتار کند و **بدون نیاز به هوش مصنوعی** خروجی قابل‌اتکا بدهد.

## پرسونای هدف
کارشناس سئو که کدنویس نیست. یک فایل CSV آپلود می‌کند؛ **بدون هیچ دکمهٔ اضافه**، سیستم خودش امبد و رتبه‌بندی می‌کند، لودینگ نشان می‌دهد، و وقتی تمام شد اعلام می‌کند. سپس برای هر صفحه فهرست پیشنهادها + دلیلِ هر رتبه را می‌بیند و CSV می‌گیرد.

## وضعیت: ارتقای کیفیت (Phase 3 — Deterministic Hybrid Ranking)
پروژه از قبل یک SPA سبک + بک‌اند Supabase است (این بخش **تغییر نمی‌کند**؛ کل داده و امبدینگ همین حالا هم روی Supabase است). تغییر نسخهٔ ۳ فقط در «مغزِ رتبه‌بندی» و «جریان کاربری» است:
1. **موتور رتبه‌بندی هیبریدی و قطعی** در Postgres جایگزین کسینوسِ خالص می‌شود.
2. **لایهٔ هوش مصنوعیِ Re-rank به‌طور کامل حذف می‌شود** (دیگر لازم نیست؛ خواستهٔ صریح کارفرما: «تا حد زیادی دیگر به هوش مصنوعی نیاز نداشته باشیم»).
3. **دلیلِ رتبه** به‌صورت قطعی از خودِ اجزای امتیاز تولید می‌شود (بدون فراخوانی مدل، بدون هزینه).
4. **جریان خودکار:** آپلود → امبدینگِ خودکار → رتبه‌بندیِ خودکارِ همهٔ صفحات → نمایش «تمام شد». دکمهٔ «شروع» حذف می‌شود.
5. **پاک‌سازی** داده را از **Supabase هم** حذف می‌کند (نه فقط حافظهٔ کلاینت).

## فلسفهٔ معماری
یک منبع حقیقت (Supabase Postgres) + دو سیگنالِ مکمل که در دیتابیس ترکیب می‌شوند:
- **سیگنال معنایی:** نزدیکیِ کسینوسیِ بردارهای `pgvector` (زمینه و مفهوم را می‌فهمد).
- **سیگنال ساختاری:** هم‌پوشانیِ وزن‌دارِ تگ‌های سئویی (شهر/کشور/تم/فصل/مناسبت/مبدأ…) که دانشِ حوزهٔ سئو را رمزگذاری می‌کند.

`final_score = α·cosine + (1−α)·structured`. این «هیبرید» است، **نه** بازگشتِ موتورِ قانون‌محورِ قدیمی (دیوار/حلقه/پُرسازی). اجزای امتیاز شفاف‌اند و مستقیماً «دلیلِ رتبه» را می‌سازند. هوش مصنوعی از منطق پایه حذف است.

## پشته تکنولوژی (Tech Stack)
| لایه | ابزار |
|---|---|
| فریم‌ورک UI | React 19 + Vite 6 |
| زبان | TypeScript |
| استایل | **Tailwind CSS v4** (RTL، فارسی، تم emerald/slate) — از طریق `@tailwindcss/vite` |
| پارس CSV | Papa Parse v5 |
| بک‌اند | **Supabase** (Postgres + `pgvector` + Edge Functions) — **تمام داده و امبدینگ اینجاست** |
| دسترسی به دیتابیس | `@supabase/supabase-js` (کلاینت رسمی — **بدون ORM**) |
| امبدینگ | **`gemini-embedding-2`** با `outputDimensionality=1536` + `taskType='SEMANTIC_SIMILARITY'` + نرمال‌سازی L2 — فقط داخل Edge Function |
| موتور رتبه‌بندی | **RPC هیبریدیِ قطعی در Postgres** (کسینوس + امتیاز ساختاریِ وزن‌دار) — بدون هوش مصنوعی |
| هوش مصنوعی چت | **حذف شد** (لایهٔ Re-rank دیگر وجود ندارد) |
| state | `useState` + `useContext` (درون‌حافظه) |
| ماندگاری کلاینت | **هیچ** (هیچ ترجیح UI ماندگاری لازم نیست؛ `localStorage` حذف می‌شود چون انتخاب مدل حذف شده) |

## قرارداد مدل‌ها (Model Registry — الزامی)
شناسهٔ امبدینگ **فقط** در یک فایل واحد تعریف و از آنجا import می‌شود (کلاینت + Edge Function مقدار را می‌گیرند):
- امبدینگ: `gemini-embedding-2` (ثابت) — `outputDimensionality=1536`، `taskType='SEMANTIC_SIMILARITY'`.
- **مدل‌های چت حذف شدند** (چون لایهٔ Re-rank حذف شده). آرایهٔ `CHAT_MODELS` و توابع مرتبط پاک می‌شوند.

> **نکتهٔ معمار:** شناسهٔ `gemini-embedding-2` همان چیزی است که کارفرما داد. اگر نام رسمی مدل تغییر کرد، فقط رجیستری را عوض کن (یک نقطه). `taskType='SEMANTIC_SIMILARITY'` و بُعد ۱۵۳۶ توصیهٔ رسمیِ Google برای «تشخیص شباهت» است و بزرگ‌ترین اهرمِ ارتقای کیفیت با کمترین هزینه است. اگر مدل بُعد ۱۵۳۶ را نپذیرفت، به ۷۶۸ برگرد (نه بیشتر؛ سقف ایندکس pgvector = ۲۰۰۰).

## نبایدهای سخت‌گیرانه (Anti-Patterns) — مطلق
| ممنوع | به‌جایش |
|---|---|
| **بازگشتِ موتورِ قانون‌محورِ قدیمی** (walls/rings/fill/engine/worker، دیکشنری‌های هاردکد، `intentAxis`، `impressionWeight`) | این‌ها قبلاً حذف شده‌اند؛ هرگز برنگردند. رتبه‌بندی فقط از RPC هیبریدی. |
| **محاسبهٔ شباهت یا امتیاز در JavaScript** (کسینوس دستی، مرتب‌سازیِ برداری در کلاینت، وزن‌دهی در کامپوننت) | تمام امتیازدهی و رتبه‌بندی **فقط در Postgres**؛ کلاینت فقط می‌خواند و نمایش می‌دهد. |
| **لایهٔ هوش مصنوعی Re-rank** (edge function `rerank`، `rerankService`، `AiRerankButton`، انتخاب مدل چت) | **کامل حذف شود.** رتبه‌بندی قطعیِ هیبریدی جایگزین است. |
| **دلیلِ رتبه با فراخوانی مدل/هوش مصنوعی** | دلیل **قطعی** از اجزای امتیاز (تگ‌های مشترک + درصد شباهت) در همان RPC ساخته و ذخیره شود. |
| **دکمهٔ «شروع» یا هر اکشن دستی برای امبد/رتبه** | پس از آپلود، جریان **خودکار** اجرا شود (embedding → ranking → done) با لودینگ. |
| **پاک‌سازی فقط از حافظهٔ کلاینت** | پاک‌سازی باید داده را از **Supabase هم** حذف کند (RPC `clear_all_data`). |
| **ذخیرهٔ بردار ایندکس‌نشده یا >۲۰۰۰ بُعد** | `vector(1536)` نرمال‌شده + ایندکس `hnsw (embedding vector_cosine_ops)`. |
| **قرار دادن `GEMINI_API_KEY` در کلاینت/باندل** | کلید فقط Secret در Edge Function. هرگز پیشوند `VITE_`. |
| **استفاده از سرور Express قدیمی (`server.ts`)** | حذف‌شده؛ کلاینت مستقیم با Supabase و Edge Functions. |
| **ORM (Prisma/Drizzle/…)** | فقط `@supabase/supabase-js`. |
| **هاردکد کردن شناسهٔ مدل در چند فایل** | فقط از Model Registry. |
| **ایمپرشن به‌عنوان سیگنال رتبه‌بندی** | رتبه‌بندی صرفاً معنایی+ساختاری؛ ایمپرشن فقط متادیتای نمایشیِ اختیاری. |
| **کامنت انگلیسی** | تمام کامنت‌ها فارسی. |
| **اجرای امبدینگ تک‌به‌تک بدون batch/backoff** | Edge Function دسته‌ای با مدیریت خطا و نرخ (همان الگوی موجود). |

## آنچه دست‌نخورده می‌ماند
معماری کلانِ «SPA + Supabase» (این‌ها همین الان درست کار می‌کنند و **نباید** بازنویسی شوند مگر جایی که نسخهٔ ۳ صراحتاً می‌گوید): اتصال Supabase، جدول `pages`، Edge Function `embed-pages` (فقط پارامترهای امبد تغییر می‌کند)، پارسر CSV (`csvService`)، تم بصری emerald/slate، RTL و فونت Vazirmatn، و فلوی کلیِ «آپلود → فهرست صفحات → دیدن پیشنهادها → export». فقط «مغزِ رتبه‌بندی»، «حذف AI»، «خودکارسازی جریان» و «پاک‌سازیِ سروری» عوض می‌شوند.
